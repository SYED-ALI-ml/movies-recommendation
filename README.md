# Movie Recommendation System

This repository contains a **Movie Recommendation System** built using Python and Streamlit. It utilizes a dataset of movies to provide personalized recommendations based on user selection.

## 🚀 Features
- **Interactive UI**: Built with Streamlit for a seamless experience.
- **Content-Based Filtering**: Recommends movies based on similarity.
- **TMDB Dataset**: Uses metadata like genres, cast, and crew for accurate suggestions.
- **Deployed on Heroku**: Easily accessible online.

## 📌 Prerequisites
- Python 3.x
- Streamlit
- Required dependencies listed in `requirements.txt`

## 🔧 Installation
1. Clone the repository:
   ```sh
   git clone https://github.com/SYED-ALI-ml/movies-recommendation.git
   cd movies-recommendation
   ```
2. Create a virtual environment:
   ```sh
   python3 -m venv env
   source env/bin/activate  # On Windows, use 'env\\Scripts\\activate'
   ```
3. Install dependencies:
   ```sh
   pip install -r requirements.txt
   ```

## ▶️ Usage
Run the Streamlit application:
```sh
streamlit run website_movie.py
```

Select a movie and get recommendations based on content similarity.

## 📜 Dataset
This system uses the **TMDB 5000 Movies** dataset, which contains metadata about movies including genres, cast, and crew information.
